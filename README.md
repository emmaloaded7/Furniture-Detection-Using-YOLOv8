# Furniture Detection Using YOLOv8

## Overview
This project uses **YOLOv8** (You Only Look Once), a deep learning model built with PyTorch, to detect furniture in images and videos.

## Classes
- Chair
- Sofa
- Table

## Technologies
- Python
- YOLOv8 (Ultralytics)
- PyTorch
- OpenCV
- Google Colab

## Dataset
[Furniture Dataset — Kaggle](https://www.kaggle.com/datasets/anandpanda3/furniture-dataset-in-yolov8)

## Features
- Train a YOLOv8 object detection model.
- Detect furniture in images.
- Process videos frame by frame.
- Display bounding boxes, class labels, and confidence scores.

## Model Training
The model was initialized with pretrained YOLOv8n weights and fine-tuned using the furniture dataset.

Training configuration:
- Epochs: 20
- Image size: 640 × 640
- Batch size: 16

- Improve detection accuracy.
